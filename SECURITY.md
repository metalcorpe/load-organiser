# Security Policy

Load Organiser is a pre-release beta; nothing is deployed and only the latest `main` is
maintained.

## Reporting a vulnerability

Report privately through GitHub:
[Report a vulnerability](https://github.com/metalcorpe/load-organiser/security/advisories/new).
Please include steps to reproduce and the commit you tested. Do not open a public issue, and do
not include real people's credentials or private records in a report.
