# Coverage: central-eastern Europe (PL, CZ, SK, HU)

Researched 2026-11-14 by claude. These are development data only. Coordinates come from OpenStreetMap
(an Overpass export of all `aeroway=aerodrome` and `sport=parachuting|skydiving` features in the
four countries; 730 elements) or, in two Slovak cases, from GPS coordinates on the operator's page.
No coordinates were guessed. The Codex MCP server failed to connect in this session, so Codex did
none of this work.

Status rule used: `active` or `seasonal` only with evidence from 2025 or later, such as a dated post,
a published 2026 calendar or a 2026 listing whose organiser page was checked. `uncertain` means the
place is a real lead but recent evidence is missing or contradicts itself.

Some evidence was read only from search-engine excerpts, not from the opened page. Each record says
so in `status_evidence` or in the source's `what` ("search view"). Facebook and Instagram were only
seen as search-result snippets. I did not sign in anywhere.

## Check

Checked 2026-11-14 by a separate skeptical pass (claude). I looked at 28 records, starting with the least certain:
- uncertain records;
- records with a single source;
- records with coordinates from an operator page;
- records with no ICAO code.

**Coordinates.** All 81 records with a position were compared with OurAirports (airports.csv) by ICAO code or by the nearest airfield.
- Every point is within 0.6 km of the named airfield in the right country, except Plzeň-Líně (1.1 km, a large airfield, still inside it) and Holíč (1.05 km).
- Holíč: the operator GPS is about 130 m outside the OSM aerodrome outline (way 224003583). It is replaced by the OSM centre, 48.81357, 17.13695.
- Boleráz: the operator GPS lies inside the OSM outline, so it is kept.
- No points are in the sea or in another town.

**Duplicates.** No ICAO code or key occurs twice, across all country files.
